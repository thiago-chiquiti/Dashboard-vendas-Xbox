Dashboard de Vendas - Xbox Game Pass

Este repositório contém um projeto de análise de dados focado no desempenho de vendas de assinaturas do Xbox Game Pass. 
O objetivo foi transformar dados brutos de vendas em informações visuais que facilitam a tomada de decisão.

1. Funcionalidades:
O dashboard permite uma análise detalhada baseada nos seguintes pilares:
  - Visão Geral de Vendas: Acompanhamento do faturamento total e volume de assinaturas.
  - Filtros Dinâmicos (Slicers): Segmentação de dados por tipo de plano (Mensal, Trimestral ou Anual), permitindo uma análise granular de cada categoria.
  - Comparativo de Planos: Visualização clara de qual modalidade de assinatura gera maior receita.

2. Formatos Disponíveis
Para garantir a melhor experiência ao usuário, disponibilizei o projeto em duas versões:

a. Versão Microsoft Excel (.xlsx)

Versão padrão de mercado, utilizando:
  - Tabelas Dinâmicas para processamento de dados.
  - Segmentação de Dados (Slicers) para interatividade.
  - Gráficos dinâmicos integrados.

b. Versão Apple Numbers (.numbers) - Alternativa para Mac

Desenvolvi uma versão exclusiva para o ecossistema Apple, aproveitando as capacidades visuais do software:
  - Gráficos Interativos: Utilização de controles deslizantes (sliders) para navegação visual.
  - Interface Minimalista: Layout otimizado para a "Tela Infinita" do Numbers, proporcionando uma visualização mais limpa e moderna.
  - Alta Performance no macOS: Ideal para quem prefere trabalhar nativamente no Mac sem perder a capacidade analítica.

3. Como Visualizar
Clone o repositório:

git clone https://github.com/thiago-chiquiti/Dashboard-vendas-Xbox.git

Abra o arquivo de sua preferência:

Se estiver no Windows ou Mac (com Office), abra o arquivo .xlsx.

Se estiver no Mac, recomendo abrir a versão .numbers para uma experiência mais fluida.
